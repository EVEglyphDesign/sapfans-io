# Provenance

Every input to this repository, recorded in the same commit that introduced it.

| Date | Artefact | Source | Extent | SHA-256 |
|---|---|---|---|---|
| YYYY-MM-DD | filename | who supplied it, or the URL it was fetched from | rows / pages / bytes | `sha256:…` |

**Rules**

1. Sources are preserved exactly as received. Derived files are additional, never replacements.
2. No value is inferred, rounded, corrected or completed. Blank stays blank.
3. If a source is superseded, append a new row and mark the old one `SUPERSEDED`. Never delete.
